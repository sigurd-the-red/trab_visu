# Trabalho de Visualização de Dados
Feito pelos alunos: Gustavo Teixeira, Miguel Enne e Pedro Chaboudt.

## Projetos
### Electric car sales — Trends in electric cars
A Agência Internacional de Energia compartilha dados sobre veículos elétricos. O dataset traz dados sobre o estoque global de carros elétricos ao redor do mundo.

### Lazy Cats — How Lazy Are Pet Cats Really?
Estudo comparativo sobre o comportamento de gatos domésticos. O dataset traz dados sobre a atividade de 28 felinos analisados durante o inverno/verão.

### Corruption Perceptions Index, 2012 to 2024
A Transparency International calcula o Índice de Percepção da Corrupção, e o Our World in Data o republica. O dataset traz a pontuação do índice, de 0 (muito corrupto) a 100 (muito limpo), de 272 países e territórios entre 2012 e 2024, com a região do mundo de cada um.

## Como rodar o projeto
### Pré-requisitos
- [Node.js](<https://nodejs.org/>) instalado.
- npm, incluído normalmente na instalação do Node.js.

### Instalação
Clone o repositório e acesse a pasta do projeto. Em seguida, instale as dependências:

```
npm install
```

### Execução
Inicie o servidor de desenvolvimento:

```
npm run dev
```

Após executar o comando, acesse no navegador o endereço local exibido no terminal.
